BEST BUY CANADA — LARGE ITEM RETURNS
Source: https://www.bestbuy.ca/en-ca/help/returns-and-exchanges/returning-or-exchanging-a-best-buy-product/returning-a-large-item

Purpose:
Use for televisions, appliances, furniture and other large-item return questions.

Key facts:
- Large-item returns are subject to the normal return policy plus product-specific conditions.
- For eligible large items, the customer should bring proof of purchase and use an eligible big-box Best Buy store to start the return process.
- Customers should not bring the large item into the store; a pickup can be scheduled.
- Large-item returns cannot be scheduled or processed at Best Buy Mobile or Best Buy Express locations.
- If an item is shipped in multiple boxes, the customer should generally wait until the final box arrives before beginning the return process.

Agent use:
Primary: Returns & Support Agent.
