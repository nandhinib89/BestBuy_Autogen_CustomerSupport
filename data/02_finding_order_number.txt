BEST BUY CANADA — FINDING AN ORDER NUMBER
Source: https://www.bestbuy.ca/en-ca/help/your-order/finding-your-order-number

Purpose:
Use for questions about locating an order number.

Key facts:
- For online purchases, the order number can be found in the order-confirmation email subject line.
- Customers using a My Best Buy account can also find it in Order History.
- For Reserve and Pick Up or Quick and Easy Store Pickup purchases, the number can be found on an emailed digital receipt or in Order History when the purchase was made through the account.
- This information can be combined with the Order Status document when a customer wants to check an order but cannot find the order number.

Agent use:
Primary: Order Agent.
